# Career expansion 0.10

Authorized scope: harbor-only shop with 100 skills, 100 parts, 100 expensive vessels; automatic pot operations, salmon-capable vessels, 50 infrequent incidents, loans repaid from landings, and hired-captain fleet with explicit spending requests and chart markers. English UI. Dependency-free static hosting. Preserve v1 saves with additive migration.

Build order / capability map:
1. catalog.mjs -> career.mjs: 20 skill disciplines × 5 ranks; 20 part systems × 5 grades; 10 vessel designs × 10 sizes. Every rank has an operational effect; higher ranks require the previous rank. Parts belong to hulls, skills to the company. Boats have distinct stats, layouts and fishing capabilities.
2. incidents.mjs -> simulation.mjs: 50 named incidents across ten failure classes. Saved deterministic RNG; first incident after 8 hours at sea, later intervals 6–14 hours, cooldown after repairs. Temporary failures block/reduce the relevant system, crew automatically repair, permanent damage/costs remain.
3. career.mjs -> simulation.mjs: buy, trade or hire; automatic deploy/haul obey speed, spacing, side, capacity and failure gates. Salmon nets set/soak/retrieve with a compatible vessel. Both catches unload together. Loan fixed 10% fee, 15% landing repayment, no compounding; bounded credit; emergency loans available at sea.
4. fleet.mjs -> simulation.mjs: independent sailing/deployment/soaking/retrieval/landing, 30% crew share after expenses. Purchases require player approval; refusal holds the vessel. Real positions and separately colored pot markers. No offline income.
5. shop.mjs + game.mjs + renderer: searchable categorized catalog, explicit boat exchange dialog, fleet/finance management accessible offshore, harbor-only purchases, dynamic boat identity/layout/size; net rendering. Existing fallback remains usable.
6. Tests and browser: catalog counts/IDs, purchases/tiers/effects, migrations, automation, net catch/landing, incidents/repair/replay, loans/debt, fleet movement/profit/requests and save continuation. Static deployment archive and instructions.

Rules: no purchase without funds; no boat exchange with cargo, deployed gear or active operation. Trade-in 65% of hull + installed equipment; captain hiring 25,000 kr, old equipment remains aboard. A fleet vessel requests fuel/repairs only when docked and cannot spend until approved. Repeat requests bounded to one per boat. Caps on discounts/reductions prevent free fuel, infinite catch or negative repair durations. Saving retains pending repairs, nets, debt and fleet operations. Harbor service panel/tow remains available at sea; shop button appears only inside harbor.

Approximations: vessel designs share a procedural hull family, with dimensions/paint/equipment variations, not 100 hand-made meshes. Fleet navigation uses offshore waypoints; crew size contributes to work rate, visible deck watch is bounded for clearance. Events are game mechanics, not maritime training. Browser local saves are per origin; deploying to a new domain requires export/import.


Verification: 64 Node tests pass, including every skill/part purchase and all 100 hull docking routes. Browser smoke tests covered search, tier gates, item purchases, trade-in/captain review, captain approval/refusal, loan accounting, offshore shop hiding, chart fleet/pots, incidents and automatic repairs, and a 172 kg salmon net landing into the hold. The real v1 season migrated with its 62,495 kr balance intact; final main-page console was clean. Native JSON file selection could not be automated because the Chrome extension lacks file-URL access; migration/roundtrip and mixed-fishery settlements were tested in Node. Browser download notification reached “Season downloaded”, but the automation download event was not available for the blob, so filesystem download completion was not independently confirmed. No browser permissions were changed.
